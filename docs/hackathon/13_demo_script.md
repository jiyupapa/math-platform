# 5분 라이브 시연 대본 — 수포자 사관학교 (12.3 시상식)

> 목표: 5분 안에 ①AI 강사(진단→경로 재구성) ②라이브 투어(심사위원 문장으로 ChatGPT 내부) ③개념 지도(같은 수학이
> 재등장한다) ④로컬 AI 튜터(다른 부 개념까지 안내, 오프라인) ⑤숫자 한 장을 보여준다. 심사위원 = **비전문가 임원** —
> 수식이 아니라 "내 입력이 움직이는 순간"으로 설득한다.

## 시연 전 체크리스트 (10분)

- [ ] **조립본으로 구동**: `npm run deploy:build` → `npm run deploy:serve` — dev 서버가 아니라
  단일 origin 조립본이어야 포털 2층(진도 통합)·개념 지도의 진도 겹치기·부 간 링크가 산다.
  (`deploy:build` 가 개념 그래프 `concept-graph.json` 도 함께 생성한다 — 별도 명령 불필요.)
- [ ] `ollama serve` 실행 + **워밍업 질문 1회** (첫 질문은 모델 로딩으로 수십 초 —
  미리 한 번 물어두면 15분간 메모리 유지). 워밍업 질문은 ④의 첫 질문과 같은 것으로.
- [ ] **진단 초기화**: 포털에서 "전체 경로 보기"(또는 `hub-diagnosis-v1` 삭제) — 첫 진단 장면을 위해.
- [ ] **진도 시드**: 1부 몇 챕터 완료 + 복습 북마크 2~3개(예: 3부 4장 조건부 확률, 5부 5장 KL 발산) 심어두기 —
  지도에 진도 배지·"복습 먼저" 카드와 함께 **"복습 경로"** 카드(★표시한 개념 → 선수 개념까지)가 떠 "쓰고 있는 플랫폼"
  인상 (완전 0% 금지).
- [ ] 4부 열어 각 랩(토큰화·임베딩·어텐션·확률·temperature)에서 **준비한 문장으로 리허설 1회** —
  입력 지원 범위(한글/영문·길이) 확인, 백업 문장 확정.
- [ ] 포털 **개념 지도** 탭 미리 열기(`/concepts?c=self-attention-qkv` — 어텐션 선택 상태) — ③ 장면은 이 탭으로 전환만.
- [ ] 브라우저 배율 125%, 알림 끄기, Wi-Fi 토글 바로 열 수 있게, 질문 3종 메모장 준비.

## 실패 모드 대비

- **심사위원 문장이 이상하거나 너무 긺** → "좋은 문장인데 화면엔 짧은 게 잘 보입니다" 하고
  준비한 백업 문장으로 전환 (백업: "우리 회사 최고의 복지는 동료다").
- **튜터 답변이 마음에 안 듦** → "지우기" 후 재질문 (맥락 초기화로 재현성 높음). 완답 5~6초 —
  스트리밍이 시작되면 말을 이어가며 기다림을 채운다.
- **튜터가 다른 부 개념에 "이 과정에 없다"고 답함** → 개념 그래프 산출물이 없는 것 — 조립본이 아닌 dev 서버를 띄웠거나
  `concept-graph.json` 미생성. `npm run ontology:graph` 후 새로고침(리허설에서 확인하면 본선에서 안 난다).
- **개념 지도에 진도·표시가 안 겹침** → 조립본(같은 origin)에서만 각 부 값을 읽는다 — 시연은 반드시 `deploy:serve`.
- **진단 중 시간 지연** → 대표 문항 3~4개만 소리 내어 풀고 나머지는 빠르게 클릭 (문항당 2~3초).
- **시간이 모자람** → ③ 개념 지도 장면(15초)을 먼저 뺀다. 튜터 ①의 답변에 "5부 4장"이 나오는 것으로 지도 이야기를 대신한다.
- **프로젝터 해상도** → 배율 125% 기본, 어텐션 히트맵·개념 지도 화면은 확대 준비.
