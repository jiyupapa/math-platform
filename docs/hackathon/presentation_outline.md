## 구간별 상세

### ① 후킹 (0:00–0:30) — 파이프라인 슬라이드
- **화면**: `presentation_pipeline.md` 슬라이드.
- **멘트**: "ChatGPT에 '오늘 날씨 어때?'라고 물으면 — 단어를 벡터로 바꾸고(ch1), 내적으로 관련도를 따지고(ch2), 행렬곱으로 섞습니다(ch3·5). 거창한 AI도 뜯어보면 선형대수입니다."
- **노림수**: 익숙한 AI로 시작 → "그게 다 우리가 배우는 수학" 폭로.

### ② 문제 제기 (0:30–1:00)
- **화면**: 랜딩(HomeView) — "유튜브 추천도, ChatGPT도 사실 선형대수입니다".
- **멘트**: "그런데 많은 사람이 수학에서 한 번 손을 놓으면 AI의 원리에 다가가지 못합니다. 설명 없는 기호 하나에서 멈추죠. 이 **수포자**들을 위해 만들었습니다."

### ③ 솔루션 소개 (1:00–1:30)
- **화면**: 사이드바 목차 + 신경망 지도(NeuralNetMap).
- **멘트**: "선형대수 8개 챕터를 **직접 만지는 웹 앱 + 진짜 계산하는 Python 노트북** 두 갈래로. 각 개념이 신경망의 어느 부품인지 지도로 연결했습니다. 핵심은 — **글자보다 움직임**입니다. 보여드리죠."

### ④ 라이브 데모 (1:30–3:45) ★핵심
> 말로 설명하지 말고 **슬라이더를 움직여 화면이 바뀌는 걸** 보여준다. 한 데모당 ~45초.

- **데모 1 (1:30–2:15) — 선형변환 `GridTransform` / `ImageTransform`**
  - 격자(또는 사진)에 2×2 행렬 슬라이더를 움직여 회전·확대·전단이 실시간 변형되는 모습.
  - 멘트: "행렬 = 공간을 변형하는 함수. 이게 신경망의 한 '층'이 하는 일입니다."
- **데모 2 (2:15–3:00) — 내적/추천 `RecommenderDemo`**
  - 취향 슬라이더를 움직이면 영화 추천 순위가 내적 점수로 실시간 재정렬.
  - 멘트: "방금 한 게 내적입니다. 추천도, 어텐션도 전부 이 계산이에요." (← ①의 어텐션과 콜백)
- **데모 3 (3:00–3:45) — PCA `PCADemo` 또는 자동채점**
  - PCADemo: 데이터 구름에서 주성분 축을 실시간 계산, PC1 투영으로 2D→1D 차원축소.
  - (대안) StepQuiz: 중간 단계까지 채점되는 문제로 "막히면 힌트, 즉시 해설" 시연.
  - 멘트: "차원축소 = AI가 핵심만 남기는 법. 그리고 배우고 나면 바로 풀어보고 채점까지."

### ⑤ 차별점 (3:45–4:15)
- **화면**: 자동채점/복습 목록/진도바 빠르게.
- **멘트**: "단순 강의가 아닙니다. **모든 기호를 즉시 설명**하고, **난이도별 문제·단계별 채점·복습 북마크·진도 저장**까지. 수포자가 끝까지 가도록 설계했습니다."

### ⑥ 마무리·로드맵 (4:15–5:00) — 로드맵 슬라이드
- **화면**: `presentation_roadmap.md` 슬라이드.
- **멘트**: "이건 1부입니다. **2부 미적분 — AI의 학습 원리**, **3부 확률통계 — AI의 불확실성**으로 이어집니다. 그리고 솔직히, 수상을 위한 데모가 아니라 **제가 실제로 이해하려고 만든 도구**라 발표 후에도 계속 발전시킬 겁니다. 감사합니다."
