```
┌──────────────────────────────────────────────────────────────────┐
│                                                                    │
│                    직접 만져봅니다                                  │
│                                                                    │
```

## 데모 진행 치트시트 (발표자용 — 슬라이드에 넣지 않음)

> 한 데모당 ~45초. **슬라이더를 움직여 화면이 바뀌는 순간**을 보여주는 게 핵심. 설명은 짧게.

### 데모 1 — 선형변환 (ch5, `GridTransform` 또는 `ImageTransform`) · 1:30–2:15
- **클릭 동선**: ch5 페이지 → 격자(또는 사진) 데모 → 회전 프리셋 → 전단 슬라이더 드래그.
- **보여줄 것**: 격자/사진이 실시간으로 기울고 돌아감. 단위 정사각형 → 평행사변형(넓이=det).
- **한마디**: "행렬은 공간을 변형하는 함수예요. 이게 신경망 한 '층'이 하는 일입니다."

### 데모 2 — 내적/추천 (ch2, `RecommenderDemo`) · 2:15–3:00
- **클릭 동선**: ch2 AI 섹션 → 액션/로맨스 취향 슬라이더 드래그 → 추천 순위 재정렬 확인.
- **보여줄 것**: 슬라이더 움직이면 영화 5편이 내적 점수로 실시간 재정렬, 1등 강조.
- **한마디**: "방금 한 계산이 내적입니다. 추천도, ChatGPT의 어텐션도 전부 이거예요." (← 후킹 슬라이드 콜백)

### 데모 3 — PCA/차원축소 (ch8, `PCADemo`) · 3:00–3:45
- **클릭 동선**: ch8 → PCADemo → "PC1으로 투영" 체크.
- **보여줄 것**: 길쭉한 데이터 구름에서 주성분 축 자동 계산 → 점들이 직선 하나로 모이는 2D→1D.
- **한마디**: "차원축소 = AI가 핵심만 남기는 법. PCA가 그걸 합니다."
- **(대안 데모)**: 시간/맥락에 따라 `StepQuiz`로 "단계별 채점·즉시 해설"을 보여줘 학습 도구 측면 강조.

## 제작 메모
- 전환 슬라이드는 **딱 1장**. 데모 중에는 슬라이드로 돌아오지 말고 앱에 머무를 것.
- 세 데모 제목을 후킹 슬라이드의 ①임베딩-②어텐션-③층과 색·번호로 **콜백**하면 일관성 ↑.
- ⚠️ 사전 준비: 데모 페이지 **탭 미리 열기**, 슬라이더 **시작값 세팅**(극단값에서 시작하면 변화 안 보임), **오프라인 폴백** 확보. (체크리스트는 `presentation_outline.md` 참고)
- 라이브 실패 대비 **화면녹화 백업** 1개 준비.
