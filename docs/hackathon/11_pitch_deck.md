## 슬라이드 구성 (14장) — 세 기둥: LLM · 개념 온톨로지 · 시스템 다이내믹스

### ① 타이틀
- **수포자 아카데미** — AI 를 가르치는 AI 강사
- 부제: "수학을 포기했던 직원도, ChatGPT 의 내부까지"
- 세 기둥 알약: **LLM 튜터 + 개념 온톨로지 + 시스템 다이내믹스**
- 숫자: 12부 · 130챕터 완결 / ₩0 완전 로컬 / 설치 0
- 비주얼: 진단 후 개인화된 포털 홈

### ② 문제 — 전 직원이 AI 를 쓰는데, 원리를 아는 사람은?
- 직원 대부분이 매일 AI 사용 — 그러나 원리 이해는 극소수. 원인: **수학**
- 기존 강의의 실패: 1→2→3 순서로 수학만 하다 **AI 를 만나기 전에 지친다**
- 말 노트: "프롬프트를 잘 쓰는 것과 도구를 이해하는 것은 다릅니다 — 이해가 있어야 한계·보안·활용을 판단합니다."

### ③ 해법 + 세 기둥
- 위: 진단(5분) → 개인 경로(규칙 엔진) → 교실 + 튜터(12부 130챕터 · 로컬 LLM)
- 아래(어두운 띠): **이 강사를 움직이는 세 기둥** — LLM 튜터(강사의 입) · 개념 온톨로지(강사의 머릿속 지도) ·
  시스템 다이내믹스(시간을 미리 돌려 보는 눈). 6~9장에서 하나씩.

### ④ 데모 1 — 진단 5분, 커리큘럼이 다시 그려진다
- 비주얼: 진단 화면 → 개인 요약 카드("55챕터 · 예상 31.9시간" + 🤖 AI 강사에게 더 듣기)
- 실측 예시: 130챕터 중 55챕터 · 31.9시간, 틀린 문항은 개념 이름(온톨로지)으로
- 말 노트: 결정은 규칙이라 같은 답이 항상 재현된다.

### ⑤ 데모 2 — LLM 해부: 내 문장이 ChatGPT 안에서 움직인다
- 비주얼: 토큰화 → 임베딩 → 어텐션 → 다음 단어 확률 → temperature 5컷
- 키 카피: "커리큘럼이 곧 LLM 해부도" — 이 플랫폼은 LLM 을 쓰기도 하지만, 무엇보다 LLM 의 속을 가르친다

### ⑥ 기둥 1 · LLM — 로컬 LLM 튜터: 개념 지도를 읽고 답하는 강사
- 왼쪽: 12부 5장(오일러법) 튜터 실화면 — "경사하강은 어디서 배워요?" → "2부 9장, 먼저 그래디언트"
- 답이 나오는 길: 질문 → 개념 카드(온톨로지, 약 100토큰) → 로컬 LLM(지금 보는 장 맥락 + 카드) → 답. 벡터 DB 없이, 결정적으로
- LLM 이 일하는 네 곳: 챕터 튜터(전 12부) · 추천 설명(규칙이 정한 경로를 강사 말투로) · 메모에서 AI에게 묻기 · 노트북 튜터
- 띠: **"결정은 규칙, 말은 LLM"** — 가드레일 10/10 · 추가 지연 0초 · 완답 5~6초 · ₩0

### ⑦ 기둥 2 · 개념 온톨로지 — 강사의 머릿속 지도: 개념 127 · 관계 517
- 비주얼: 개념 지도에서 12부 "S자 성장"을 고른 화면 — 선수 사슬이 2부 시그모이드·지수와 로그까지 이어진다
- 카드: 개념 127 · 관계 517(12부 SD 개념 13개 포함) / 읽는 곳 9 / 커밋마다 검사(본문 링크 185)
- LLM 이 이 지도를 읽으면(튜터 실측): 카드 없이 "N부 2장"(자리표시자) → 카드 붙이면 "2부 6장, 먼저 도함수 2부 3장"

### ⑧ 기둥 3 · 시스템 다이내믹스 — 시간을 미리 돌려 보는 눈: 인과지도와 저량-유량도
- 비주얼: 7장 인과지도(입소문 R · 포화 B, "굵은 화살표가 이기는 고리") · 12장 캡스톤 저량-유량도(잠재 사용자 → 도입 → 사용자 → 이탈)
- 같은 수학, 다른 이름: 오일러법 = 경사하강(학습률 = 시간 간격) · 1차 지연 = EMA(모멘텀·Adam) · S자 성장 = 시그모이드
- AI 가 만드는 고리(모델 붕괴·보상 해킹·데이터 플라이휠) · 12부 13챕터(실험실 13개 · 노트북 13권)

### ⑨ SD 활용 — 이 플랫폼의 사내 확산도 같은 모형으로 돌려 봤습니다
- 막대그래프(캡스톤 모형, 직원 3,000명 가상 회사, 평균 10개월 쓰면 그만두는 현실): 3년 뒤에도 쓰는 사람 비율
  그대로 75.8% · 홍보 3배 77.2% · **입소문 1.5배 83.7%** · **이탈 방지(평균 20개월) 87.8%**
- 절반 도달(이탈이 없을 때): 그대로 9.1개월 · 홍보 3배 6.4개월 · 입소문 1.5배 6.8개월
- 결론: **속도는 홍보가 당기고, 남는 사람 수는 입소문과 이탈 방지가 정한다** → 파일럿 참가자 = 입소문의 씨앗,
  기기 간 진도 동기화·복습 표시·협업 메모 = 이탈 방지 장치
- 주의 문구: 가정한 계수로 돌린 모형 시나리오(예측 아님), 파일럿 실측으로 계수를 바꾼다. 12부 12장 실험실·노트북으로 재현 가능
