## 슬라이드 구성 (11장)

### ① 타이틀
- **수포자 사관학교** — AI 를 가르치는 AI 강사
- 부제: "수학을 포기했던 직원도, ChatGPT 의 내부까지"
- 비주얼: 포털 경로 지도 스크린샷 (배경 흐리게)

### ② 문제 — 전 직원이 AI 를 쓰는데, 원리를 아는 사람은?
- 직원 대부분이 매일 AI 사용 — 그러나 원리 이해는 극소수. 원인: **수학**
- 기존 강의의 실패: 1→2→3 순서로 수학만 하다 **AI 를 만나기 전에 지친다**
- 말 노트: "프롬프트를 잘 쓰는 것과 도구를 이해하는 것은 다릅니다 — 이해가 있어야 한계·보안·활용을 판단합니다."

### ③ 해법 — 강사처럼: 진단하고, 경로를 짜고, 옆에서 가르친다
- 3층 구조 다이어그램: **진단(5분) → 개인 경로(규칙 엔진) → 학습(11부 교실) + 튜터(로컬 LLM)**
- 키 카피: "강의가 아니라 **강사**입니다"

### ④ 데모 1 — 진단 5분, 커리큘럼이 다시 그려진다
- 비주얼: 진단 전(13단계 전체) → 진단 후(접힌 단계·개인 요약 "N챕터 · M시간") 비교 스크린샷
- 포인트: **결정은 규칙**(근거가 화면에) — 심사위원 질문 "왜 이 경로냐"에 화면으로 답함
- 말 노트: 시연에서 임원이 직접 진단 — 그 자리에서 "그 사람의 지도"가 되는 순간. 틀린 문항은 개념 이름
  ("다시 볼 개념: 연쇄법칙(2부 6장)")으로 돌아온다는 것도 한 문장으로.

### ⑤ 데모 2 — 내 문장이 ChatGPT 안에서 움직인다 (라이브 투어)
- 비주얼: 토큰화 → 임베딩 → 어텐션 히트맵 → 다음 단어 확률 → temperature 5컷 스트립
- 키 카피: "여러분의 문장으로 라이브 시연"
- 말 노트: 각 컷이 1·3·5부 수학과 1:1 — "커리큘럼이 곧 ChatGPT 해부도"

### ⑥ 개념 온톨로지 — 같은 수학이 여러 부에 다시 나온다, 그 지도를 한 파일로 (신설 2026-09-07)
- 비주얼: **개념 지도** 스크린샷(`assets/concept_map.png`) — KL 발산을 누른 상태, 먼저 알아야 하는 사슬(실선)과 그 개념을
  쓰는 다음 개념(점선)이 이어진 화면
- 카드 3장: **개념 114 · 관계 446**(정본 파일 하나) / **읽는 곳 9**(검색·튜터 웹·노트북·챕터 띠·개념 지도·용어 대조표·복습
  경로·진단·질문 집계) / **커밋마다 검사**(위치·앵커·선수 순환·본문 링크 151 — 콘텐츠의 린터)
- 하단 실측 한 줄: 카드 없이 "N부 2장"(자리표시자) → 카드 붙이면 "2부 6장, 먼저 도함수 2부 3장"
- 말 노트: 시리즈의 핵심 주장("같은 수학이 재등장")을 화면 하나로. 예상 질문 두 개 — "그냥 JSON 아닌가요?"(관계에 타입,
  검사기, 아홉 곳이 같은 답 — 형식이 아니라 계약) / "왜 벡터 DB·RAG 로 안 했나?"(129개 장 규모엔 큐레이션 그래프가 더
  정확·결정적·오프라인, 7부 8장이 이 기법 자체를 가르친다)

### ⑦ 완전 로컬 — 서버 0 · 비용 ₩0 · 데이터 유출 0
- 비주얼: Wi-Fi OFF 아이콘 + 튜터 답변
- 3줄: 정적 웹(서버 불필요) / 로컬 LLM 튜터(질문 무제한 ₩0) / 질문 외부 전송 0건
- 시연 밴드: **Wi-Fi 를 끄고 튜터에게 다른 부의 개념을 묻는다** — "KL 발산은 어디서 배워요?" → "5부 5장, 먼저 크로스
  엔트로피(5부 4장)" (개념 그래프의 카드 한 장 ≈ 100토큰, 벡터 DB 없이, 경량 로컬 모델)
- 덤: 9부가 이 인프라 자체를 가르침 — "7B 모델이 왜 4GB 로 내 PC 에서 도는가"
