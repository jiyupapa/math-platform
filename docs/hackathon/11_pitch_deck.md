## 슬라이드 구성 (10장)

### ① 타이틀
- **수포자 사관학교** — AI 를 가르치는 AI 강사
- 부제: "수학을 포기했던 직원도, ChatGPT 의 내부까지"
- 비주얼: 포털 경로 지도 스크린샷 (배경 흐리게)

### ② 문제 — 전 직원이 AI 를 쓰는데, 아무도 원리를 모른다
- 직원 대부분이 매일 AI 사용 — 그러나 원리 이해는 극소수. 원인: **수학**
- 기존 강의의 실패: 1→2→3 순서로 수학만 하다 **AI 를 만나기 전에 지친다**
- 말 노트: "프롬프트를 잘 쓰는 것과 도구를 이해하는 것은 다릅니다 — 이해가 있어야 한계·보안·활용을 판단합니다."

### ③ 해법 — 강사처럼: 진단하고, 경로를 짜고, 옆에서 가르친다
- 3층 구조 다이어그램: **진단(5분) → 개인 경로(규칙 엔진) → 학습(9부작 교실) + 튜터(로컬 LLM)**
- 키 카피: "강의가 아니라 **강사**입니다"

### ④ 데모 1 — 진단 5분, 커리큘럼이 다시 그려진다
- 비주얼: 진단 전(11단계 전체) → 진단 후(접힌 단계·개인 요약 "N챕터 · M시간") 비교 스크린샷
- 포인트: **결정은 규칙**(근거가 화면에) — 심사위원 질문 "왜 이 경로냐"에 화면으로 답함
- 말 노트: 시연에서 임원이 직접 진단 — "그 사람의 지도"가 되는 순간이 와우 포인트 1

### ⑤ 데모 2 — 당신의 문장이 ChatGPT 안에서 움직인다 (라이브 투어)
- 비주얼: 토큰화 → 임베딩 → 어텐션 히트맵 → 다음 단어 확률 → temperature 5컷 스트립
- 키 카피: "본부장님 문장으로 라이브 시연" — 와우 포인트 2
- 말 노트: 각 컷이 1·3·5부 수학과 1:1 — "커리큘럼이 곧 ChatGPT 해부도"

### ⑥ 완전 로컬 — 서버 0 · 비용 ₩0 · 데이터 유출 0
- 비주얼: Wi-Fi OFF 아이콘 + 튜터 답변 스크린샷
- 3줄: 정적 웹(서버 불필요) / 로컬 LLM 튜터(질문 무제한 ₩0) / 질문 외부 전송 0건
- 덤: 9부가 이 인프라 자체를 가르침 — "튜터가 왜 4GB 로 내 PC 에서 도는가"

### ⑦ 숫자 한 장 [전수 실측]
- **96** 학습 챕터 · **1,300+** 자동채점 문항 · **107** 실습 노트북 · **₩0** 운영비
- 핵심 경로 55챕터 ≈ **37시간** (진단으로 개인별 추가 단축)
- 튜터 실측: 완답 5~6초 · 가드레일 10/10 차단 · 추가 지연 0초

### ⑧ 품질 — 수포자 페르소나 검수 + 자동 검증 3종
- 페르소나 검수: 이탈 위험 40여 건 발견 → 전량 수정 → "학습 적합" 판정(전 부 동일 기준)
- 자동 검증: 전 10앱 타입체크·빌드 / 노트북 107개 무에러 실행 / 브라우저 E2E(개인화 통합 16항목)
- 말 노트: "콘텐츠도 소프트웨어처럼 회귀 테스트를 돕니다"

### ⑨ 도입 — 오늘 바로 시작할 수 있습니다
- 도입 시나리오: 신입 온보딩 · 전사 AI 리터러시 교육 · 실무 직결 트랙(7부 RAG — 사내 챗봇의
  수학, 9부 — 사내 PC 로컬 모델 선택)
- 온보딩 마찰 0: URL/QR 로 즉시 접속, 로그인 없음, 진도 자동 저장
- QR 코드 (배포 URL) <!-- TODO: 호스트 확정 후 -->

### ⑩ 로드맵 + 클로징
- 파일럿(동료 5~10명, 완주율·이탈 지점) → 도입 지점 확정 → 계정·서버 진도(백엔드)
- 콘텐츠 확장 후보: 스케일링 법칙과 평가의 통계
- 클로징 카피: "전 직원의 AI 리터러시 — **비용 0원으로, 오늘부터.**"

- 발표 5분이면 ④⑤(데모 2장)는 슬라이드 대신 **실물 시연**으로 대체하고 나머지 8장을 빠르게.
- 임원 청중 대비: 수식·코드 화면 금지, "내 문장·내 진단"의 1인칭 경험 강조.
