## 4. 비용 (API 정가 환산)

> Claude Code **종량제(API) 정가** 기준 환산액이다. 실제 작업이 구독제(Max 등)로 이뤄졌다면 실지출은
> 월 정액이며 이 값이 아니다 — 규모 감각용 **명목값**. 캐시 쓰기 TTL(5분 vs 1시간)을 알 수 없어 범위로 제시.
> 환율 가정 **US$1 = ₩1,400**(최신 환율로 재곱). 단가(1M 토큰당 입력/출력): Fable 5 $10/$50 · Opus 4.8 $5/$25 ·
> Haiku 4.5 $1/$5, 캐시 쓰기 = 입력×1.25(5분)~2(1시간), 캐시 읽기 = 입력×0.1. (2026-07 `claude-api` 정가표.)

| | 하한(5분 캐시) | 상한(1시간 캐시) |
|---|---|---|
| **합계** | **$7,615 (~₩1,066만)** | **$8,618 (~₩1,207만)** |

## 5. 한계·주의

- **비용은 API 정가 환산 명목값**이다 — 구독제(Max 등)로 작업했다면 실지출은 월 정액. 환율·캐시 TTL 가정에 따라 ±약 14% 흔들린다.
- **이 PC에 보존된 세션 기준**이다. 다른 기기 작업이나 정리·삭제된 세션이 있으면 빠진다
  (디렉토리 구성상 2026-06-17 기원부터 온전해 보임).
- **실작업 60시간**은 메시지 간격 휴리스틱(5분 임계) 추정치 — 정확한 스톱워치 값이 아니다.
- 6·7·8·9·10·11부 등 모노레포 이후 제작분은 모두 `C--STUDY-MATH-PLATFORM` 세션에 포함된다
  (별도 디렉토리 없음).
- 스냅샷 시점(2026-07-14) 이후 세션은 반영되지 않는다.

## 6. 집계 방법 (재현용)

```
대상: ~/.claude/projects/ 의 이름에 'MATH' 포함된 디렉토리 8곳의 *.jsonl 전수
토큰: 각 assistant 메시지의 message.usage.{input,output,cache_creation,cache_read}_tokens 합산
시간: 전 파일의 message timestamp 를 병합·정렬 → 인접 간격 ≤ 300초만 활동시간으로 누적
      활동일 = timestamp 가 존재하는 서로 다른 날짜 수
비용: 모델별 Σ(input×입력단가 + output×출력단가 + cache_create×입력단가×[1.25|2] + cache_read×입력단가×0.1)
```

> 참고: `npx ccusage` 로도 일자·모델별 사용량/비용을 직접 조회할 수 있다.
