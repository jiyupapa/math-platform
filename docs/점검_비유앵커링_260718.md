# 점검 기록 — 비유 앵커링 전수 점검 (2026-07-18)

> 시리즈 규칙(루트 CLAUDE.md 철학 2): **비유어를 만들면 같은 자리에서 실제(수학·실무·논문) 용어와
> 짝짓는다.** 비유만 있으면 학습자가 다른 수학 콘텐츠(교재·강의·검색)와 매칭을 못 한다.
> 11개 부 129챕터(웹, 약 3.8만 줄) 전수 점검 — 부별 병렬 검수 후 종합.

## 결과 요약

- **확정 위반 9건**(A 5 · B 2 · C 2) + 의심 다수. 확정 A+B 7건과 지목 의심 4건(계 11건)은
  **당일 수정 완료**(각 부 `docs/99_history.md` 2026-07-18 항목 참조).
- 전반 준수도는 높음. 특히 **6~11부는 "이름표 카드 + 종장 치환표" 이중 앵커 체제**가 잘 작동
  (6부 "조련"=post-training·파인튜닝·정렬 짝짓기 온전 확인). 확정 위반은 초기 제작분(1~3부)에 집중.

## 수정 완료 (11건)

| 위치 | 비유어 | 짝지은 표준 용어 |
|---|---|---|
| 1부 4장 | 계단 | 행사다리꼴(row echelon form) |
| 1부 8장 | 정보량·정보 비율 | 분산(variance)·explained variance ratio |
| 2부 1장 | 골짜기 | 최솟값(minimum) |
| 3부 10장 | 오르막/내리막 | 양의/음의 상관(positive/negative correlation) |
| 4부 1장 | 마침표 | EOS 토큰(end-of-sequence) |
| 5부 3장(+4장 역참조) | 몰빵 | 원핫(one-hot) |
| 5부 5장 | 덮개형/집중형 | mode-covering/seeking · forward/reverse KL |
| 8부 전체 | 갈라짐↔벌어짐 혼용 | "벌어짐"으로 통일(웹+노트북+검색 사전) |
| 9부 워밍업 | 1 삼키기 | 흡수(absorption) |
| 10부 워밍업 | 신의 시점 | 참값(ground truth) |
| 11부 워밍업 + 3장 | 신의 시점 · 놓침/헛발 | ground truth · 거짓 음성/양성(FN/FP)+혼동 행렬 |

### ② 하지 말 것 — 의도적 보류 (이유 있음)

- **회색 지대에 억지 앵커 금지**: 7부 "길이 오염"·"희석/찢김", 8부 "서성임", 9부 "칸".
  → 짝지을 **확립된 실무 용어가 없다.** 비슷한 영문을 지어 붙이면 존재하지 않는 검색 열쇠말을
  가짜로 주는 셈이라 비유만 있는 것보다 나쁘다. 표준어가 생기면 그때 붙인다.
- **실익 미미**: 2부 "상류 기울기"(이미 국내 교재 표준 역어), 10부 맥니마·부호 검정(한글 검색 가능),
  4부 워밍업 차트 라벨 "점수"(본문·퀴즈 앵커 온전), 랩 컴포넌트 내부 문구 — 본문 앵커가 있는
  챕터 안의 장식이라 배움이 달라지지 않는다.
- 3부 "질병 검사 역설"(기저율 오류 base rate fallacy)·"가짜 유의"(Type I error) — 구성 개념이
  전부 표준어로 앵커돼 있고 1회성이라 경계선. 굳이 하려면 ①에 얹어도 되나 우선순위 낮음.
