## 1. 왜 넣나

- **시리즈의 빈칸.** 2부는 "쌓인 양에서 변화율로"(미분)만 다룬다. 적분, 미분방정식, 시간에 따라 변하는 시스템은
  장 목록 어디에도 없다. 저량·유량은 "변화율이 쌓여 양이 된다"를 기호 없이 가르치는 방법이다.
  욕조 문제는 MIT 경영대학원생도 많이 틀렸다는 연구(Booth Sweeney & Sterman, 2000)가 있을 만큼 학력과 상관없이 어렵다.
- **설계 철학과 같은 순서.** 인과지도(그림) → 저량-유량도에 다이얼을 단 시뮬레이션(조작) → 미분방정식(수식).
- **AI 연결이 정확하다.** 비유가 아니라 같은 식이다.
  - 경사하강 = 경사 흐름(dθ/dt = −∇L)을 오일러법으로 푼 것, 학습률 = 시간 간격(DT).
    8부 2장의 발산 경계(보폭 × 곡률 < 2)가 오일러법의 안정 조건(DT < 2τ)과 같은 식이다.
  - 8부 4장 EMA = 1차 정보 지연(β = 1 − DT/τ). Adam 의 β₁ = 0.9 는 약 10걸음, β₂ = 0.999 는 약 1,000걸음 지연.
  - 로지스틱 성장 곡선 = 2부 7장 시그모이드.
  - 모델 밖: 합성 데이터 재학습의 모델 붕괴, 보상 해킹·아첨, 데이터 플라이휠이 모두 피드백 구조다.
- **도입 목적.** Bass 확산 모형이 곧 "사내 AI 도입이 어떻게 퍼지나"의 모형이다. 인력·예산·적체처럼
  LLM 내부에 관심 없는 기획·관리 직군도 업무에 바로 쓰는 도구라 사용층이 넓어진다.
  해커톤 심사위원(본부장·그룹장)에게도 바로 와닿는 장면이 된다.

## 2. 정체성

- **트랙**: 선택 분기(7~11부와 같은 자리), 역할 칩 '전략'.
- **시리즈 질문 사슬**: 6부 "무엇을 배우게 할까" · 8부 "어떻게 잘" · 9부 "무엇으로 담나" · 10부 "얼마나 키우고, 정말 좋아졌나" ·
  11부 "이제 일을 맡겨도 되나" → 12부 "**들이고 나면 시간이 지나며 무슨 일이 벌어지나**".
- **핵심 한 줄**: "쌓인 것은 흐름으로만 바뀌고, 흐름은 쌓인 것을 보고 정해진다."
- **도달점**: 12장 캡스톤. 가상 회사의 AI 도입을 저량-유량 모형으로 돌려 보고, 홍보·입소문·이탈 방지 중
  어느 다이얼이 속도와 최종 수준을 정하는지 판정서로 쓴다.
- **선수 지식**: 2부 2장(변화율)·7장(지수·시그모이드) 권장. 변화율 감각은 자체 포함한다.
  2부 9장(경사하강)·8부 2·4장(학습률·EMA)을 봤다면 5·6장의 AI 연결이 완성된다(안 봤어도 그 자리에서 최소 직관 제공).
- **중심축**: 저량-유량도와 시뮬레이션. Thinking in Systems 류의 정성적 이야기(원형·레버리지 포인트)는 10장 한 장으로 둔다.
  교양서 요약이 되면 "AI 수학" 시리즈 안에서 이 부만 겉돈다.

## 4. 이 부의 비유 체계 (비유 ↔ 실무 용어, 같은 자리에서 짝짓기)

| 비유 | 실무 용어 |
|---|---|
| 욕조의 물 높이 | 저량(stock) |
| 수도꼭지·배수구 | 유입·유출(inflow·outflow) = 유량(flow) |
| 눈덩이 | 강화 루프(reinforcing loop, R) |
| 온도 조절기 | 균형 루프(balancing loop, B) |
| 샤워기 온도 맞추기 | 지연(delay)이 만드는 과잉 교정(overshoot)과 출렁임(oscillation) |
| 시간을 잘게 썰기 | 오일러법(Euler's method)과 시간 간격(DT, time step) |

짝지을 실무 용어가 없는 비유는 만들지 않는다(비유 앵커링 점검 ②).

## 8. 실습 원칙과 정확성 함정

- **전부 오프라인·결정적.** 시뮬레이션은 오일러 반복(웹은 TS, 노트북은 numpy). 같은 DT·초기값이면 웹과 노트북 수치가 같아야 하고
  노트북 assert 로 고정한다(10·11부 전례). 11장 모델 붕괴도 난수 없이 해석적으로(±2σ 절단 정규분포의 분산 비율) 계산한다.
- **고정 모형 + 다이얼.** 범용 다이어그램 편집기는 만들지 않는다. 인과지도·저량-유량도 그림은 SVG 에 `--c-*` 토큰(다크 모드).
- **외부 SD 도구 설치를 요구하지 않는다.** Vensim·Stella·PySD 는 "실무에선 이런 도구를 쓴다" 소개만.
- **회사·제품은 가상.** 캡스톤 회사도 가상의 이름(임직원 300명 — 2026-10-14 실제 회사 규모에 맞춰 3,000명에서 바꿈). Bass 계수의 연구 평균(p ≈ 0.03, q ≈ 0.38, Sultan 외 1990)은 출처와 함께만 쓴다.
- **인과지도 극성은 정확히.** "+ 는 원인이 늘면 결과가 '다른 조건이 같을 때보다' 커진다"는 뜻이다. 유량 → 저량 화살표의 + 는
  "저량이 늘어난다"가 아니라 "유량이 클수록 저량이 원래보다 커진다"(Richardson 1986). 9장의 핵심 함정.
- **"같은 식"이라고 할 때 조건을 쓴다.** 경사하강 = 오일러법, 모멘텀 = 무거운 공(heavy ball)의 이산화, EMA = 1차 지연은
  정확한 대응이지만 안정 경계 같은 수치는 2차 함수·1차원에서의 이야기임을 명시한다.
- **장난감 모형임을 밝힌다.** 모델 붕괴는 Shumailov 외(Nature, 2024)의 현상을 단순화한 것. 원 논문과 다른 점을 한 줄로 적는다.
- **책 내용을 옮기지 않는다.** Thinking in Systems·제5경영의 문장·목록을 그대로 쓰지 않고 일반 개념만, 출처를 밝혀 쓴다.
- 기존 부 규칙 그대로: 장마다 AI 연결 카드(`ConceptCard tone="ai"`), 미니체크 2~3 + 10문제 `QuizSet`(계산형은 `StepQuiz`),
  부 간 링크는 지정석에만 `PartLink`, 분량은 줄이지 않는다.
