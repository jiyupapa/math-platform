수포자를 위한 미분 학습 프로그램을 만들고 싶어. 대상은 수포자야. 단계별 자세한 설명과 챠트, 이미지등을 이용해서 공부하고 실습할 수 있도록 하는 프로그램이야.
한꺼번에 만들지 않고 네가 제시하는 phase별로 만들고 싶어.
새로운 용어나 기호, 수식이 나오면 반드시 설명이 필요해.
이 프로젝트의 최종목표는 미분 지식을 이용해서 AI 관련 기반지식을 갖추려는 목적이다.

[개발환경] 
- 웹 앱(브라우저) Vue.js + Python 노트북을 함께 제공
- 실습은 인터랙티브 시각화 + 자동 채점 문제
- 대상은 개발자 → 본격 빌드 파이프라인 OK

[요구사항]
- 요구: 계산형 문제는 최종 답만 받지 말고 공식대로 중간 단계를 입력하게.
- 문제 제출 유형: 기본 3종 — 객관식 + 참/거짓(O·X) + 숫자입력
- 문제 제출 구성: 본문 중간 미니체크 + 챕터 끝 난이도별 10문제 세트
