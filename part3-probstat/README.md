# 수포자를 위한 확률과 통계 (시리즈 3부)

수학을 포기했던 개발자를 위한 **확률과 통계 인터랙티브 학습 프로그램**입니다.
동전을 직접 던져보고, 데이터가 종 모양으로 쌓이는 걸 눈으로 보고, 바로 문제를 풀며 "감"을 잡습니다.

> **최종 목표** — 확률·통계 지식으로 AI 기반지식을 갖춘다:
> AI 는 **확률로 예측**하고(소프트맥스·다음 단어 확률) **데이터로 배운다**(표본·손실·회귀).

시리즈: [1부 선형대수](../linear-algebra) · [2부 미분](../differentiation) · **3부 확률과 통계 (이 저장소)**

## 구성

| 갈래 | 위치 | 역할 |
|------|------|------|
| 웹 앱 | `web/` | 직관·인터랙티브 시각화·자동채점 문제·진도 관리·복습 목록·AI 튜터 |
| 노트북 | `notebooks/` | 웹 챕터와 1:1 짝 — 배운 것을 Python 으로 직접 계산 (선택 사항) |

## 커리큘럼 (Phase 0~10)

워밍업(동전 던지기) → 평균·중앙값 → 분산·표준편차 → 확률의 기초 → 조건부 확률·베이즈 →
확률변수·이항분포 → 정규분포 → 큰 수의 법칙·중심극한정리 → 추정·신뢰구간 → 가설검정·p값 →
상관·회귀(머신러닝의 시작). 자세한 계획은 `docs/00_plan.md`.

## 웹 앱 실행

```bash
cd web
npm install
npm run dev      # http://localhost:5173
```

## 노트북 실행 (선택)

```powershell
cd notebooks
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

처음이라면 `notebooks/README.md` 의 상세 안내를 따라 하세요.

## 학습 방식 (수포자 원칙)

- 새 용어·기호는 나오는 즉시 "이름 + 읽는 법 + 뜻"으로 설명
- 직관(시각화) 먼저, 공식은 나중
- 본문 중간 미니체크 + 챕터 끝 난이도별 10문제 (모두 맞히면 진도 완료)
- 계산 문제는 중간 단계를 하나씩 입력하며 확인 (`StepQuiz`)
- 평균의 함정, P(A|B)≠P(B|A), p값의 오해, 상관≠인과 같은 **흔한 착각을 명시적으로 교정**
