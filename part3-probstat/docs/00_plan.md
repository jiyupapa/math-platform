> 최종목표: **확률·통계 지식을 이용해 AI 기반지식(AI 는 확률로 예측하고 데이터로 배운다)을 갖춘다.**

## 1. 개발환경

- **웹 앱(브라우저):** Vue 3 + Vite + TypeScript + Tailwind v4 + Pinia + vue-router
- **실습 노트북:** Python Jupyter (`numpy` · `matplotlib` · `scipy` · `jupyterlab`)
- 대상이 개발자이므로 본격 빌드 파이프라인 사용 OK
- 참조 프로젝트: `C:\STUDY\MATH\part2-differentiation` (2부 — 구조·컴포넌트 복제 기반),
  `C:\STUDY\MATH\part1-linear-algebra` (1부 — 공통 컴포넌트의 원조)

## 2. 학습 방식 요구사항 (1·2부와 동일)

- 단계별 자세한 설명 + 차트 + 인터랙티브 시각화 — **직관 먼저, 공식 나중**
- **새 용어·기호·수식이 나오면 반드시 설명**(`ConceptCard`) — 기호는 "이름 + 읽는 법 + 뜻" 세트로
- 계산형 문제는 최종 답만 받지 않고 **공식대로 중간 단계를 입력**하게 한다(`StepQuiz`)
- 문제 유형 3종: **객관식 + 참/거짓(O·X) + 숫자입력**
- 문제 구성: **본문 중간 미니체크 2~3개** + **챕터 끝 난이도별 10문제 세트**(완료 시 진도 처리)
- 다른 자료를 찾아보지 않아도 여기서 학습을 완료할 수 있게 **자기완결적으로** 쓴다

## 4. 커리큘럼 (확정, 종착점 = 확률로 예측하고 데이터로 배우는 AI)

모든 챕터가 "AI 는 확률로 말하고(소프트맥스·다음 단어 확률) 데이터로 배운다(표본·손실·회귀)"라는
종착점을 향하도록 배열. ★ = 핵심 챕터.

| Phase | 챕터 | 핵심 | AI 연결고리 |
|-------|------|------|------------|
| **0** | 샘플 — 동전 던지기 맛보기 | 확률 = 장기 비율 | AI 는 확률로 말한다 |
| **1** | 데이터를 한눈에 | 평균·중앙값·최빈값·이상치·히스토그램 | 데이터 요약 = ML 의 시작, 평균 = 베이스라인 모델 |
| **2** | 흩어짐 재기 | 편차·분산·표준편차·z점수 | 특성 표준화가 학습을 안정화 |
| **3** | 확률의 기초 | 표본공간·여사건·덧셈/곱셈법칙·독립 | 언어모델 = 다음 단어 확률분포, 소프트맥스 |
| **4** | **조건부 확률·베이즈 정리** ★ | P(A\|B)·자연 빈도·질병 검사 역설 | 나이브 베이즈 스팸 필터, 믿음 업데이트 |
| **5** | 확률변수와 확률분포 | 기댓값·베르누이·이항분포 | 분류 출력 = 확률분포, 기대 손실 최소화 |
| **6** | **정규분포** ★ | 확률 = 넓이·68-95-99.7·표준화 | 가중치 초기화, 디퓨전의 노이즈 |
| **7** | **큰 수의 법칙·중심극한정리** ★ | 표본평균의 분포·표준오차 σ/√n | 미니배치(SGD)가 동작하는 이유 |
| **8** | 표본으로 전체 알기 | 모집단/표본·95% 신뢰구간 | 모델 성능 지표의 오차범위 |
| **9** | 가설검정과 p값 | 귀무가설·유의수준·A/B 테스트 | 모델 비교·배포 결정 |
| **10** | **상관관계와 회귀** ★ | 상관계수 r·최소제곱법 | 회귀 = 가장 작은 ML, 1·2부와 대단원 연결 |

각 챕터 = (1) 웹 인터랙티브 본문 + 본문 중간 미니체크 + 챕터 끝 난이도별 10문제 + (2) 짝 Jupyter 노트북.

### 시리즈 연결 (3부작 대단원)

- 2부 계획서의 후속 학습 메모("확률·통계에 개념적 적분 직관이 필요")를 반영해
  6장에서 **"확률 = 곡선 아래 넓이 = 잘게 쪼개 더한 것"** 수준의 적분 직관을 다룬다. 적분 테크닉은 다루지 않는다.
- 10장 회귀에서 **손실(잔차제곱합) 최소화**가 등장하며 2부(미분·경사하강법)와 연결되고,
  변수가 많아지면 1부(선형대수·행렬)가 필요함을 안내 — 시리즈 전체가 하나로 묶인다.

## 5. 확률·통계 전용 신규 시각화

| 컴포넌트 | 챕터 | 내용 |
|----------|------|------|
| `CoinFlipSim` | 0 | 동전 던지기 시뮬레이터 — 비율이 0.5 로 수렴 |
| `MeanMedianExplorer` | 1 | 점 드래그 → 평균(시소 받침)·중앙값 실시간 |
| `HistogramBuilder` | 1 | 히스토그램 계급 폭 조절 |
| `DeviationExplorer` | 2 | 편차 막대·제곱 넓이·표준편차 실시간 |
| `DiceSim` | 3 | 주사위 2개 합 시뮬레이터 — 삼각형 분포 |
| `BayesGrid` | 4 | 1000명 자연 빈도 그리드 — 유병률/정확도 슬라이더 → 사후확률 |
| `BinomialExplorer` | 5 | 이항분포 n·p 슬라이더 |
| `NormalExplorer` | 6 | 정규분포 μ·σ 슬라이더 + 구간 넓이 색칠 |
| `GaltonBoard` | 6 | 갈톤 보드 애니메이션 — 우연이 쌓여 종 모양 |
| `CLTSimulator` | 7 | 모집단 분포 선택 → 표본평균 히스토그램 누적 |
| `CISimulator` | 8 | 신뢰구간 100개 생성 — 참값을 놓친 구간 표시 |
| `ABTestSimulator` | 9 | A/B 전환율 실험 + p값 |
| `RegressionExplorer` | 10 | 점 드래그 → 최소제곱선·상관계수·잔차 실시간 |
