## 결론 요약

- **콘텐츠(수학 설명)는 비개발자에게도 그대로 통한다** — 수포자 배려(모든 기호 즉시 설명, 직관 먼저, 자동채점, 힌트)는 이미 설계에 내장.
- 걸림돌은 전부 **"실행 환경" 층**에 몰려 있다. 비개발자의 이탈 지점은 수학이 아니라 **첫 30분의 환경 설정**이다.
- 최우선 완화 2건 = **웹 앱 정적 배포** + **노트북 Colab 경로**. 이 둘이면 첫 30분이 거의 0이 된다.

## 1. 장애요소 (심각도 순)

### ① 터미널이라는 관문 — 최대 장벽

- 모든 진입 경로가 CLI 를 통과한다: `git clone` → `npm install` → `npm run dev` / `python -m venv` → …
- 비개발자에게는 명령어 이전에 "터미널을 연다"부터가 벽.
- 특히 **웹 앱이 배포 URL 없이 로컬 실행 전제**인 것이 가장 아픈 지점 — 비개발자에게 가장 맞는 매체(브라우저 클릭만)가 가장 깊은 곳에 잠겨 있다.

### ② Python 노트북 설치 체인 — 실패 지점 5곳의 연쇄

1. Python 설치 (PATH 체크박스 함정)
2. venv 생성
3. `Activate.ps1` — **PowerShell 실행 정책(ExecutionPolicy)이 기본값에서 차단**하는 고전 함정
4. `pip install -r requirements.txt`
5. **커널 등록/선택** — 개발자인 본인도 걸려서 requirements.txt 에 안내를 추가했던 함정
   (노트북이 시스템 Python 커널로 실행돼 `No module named ...` 오류)

- 개발자도 걸린 단계(⑤)를 비개발자가 통과할 확률은 낮다.
- 노트북 UX 자체(Shift+Enter, Run All, 커널 재시작)도 처음엔 낯설다.

### ③ AI 튜터 = Ollama 로컬 설치

- `ollama pull` + 로컬 서버 + RAM 요구 — 시리즈에서 가장 개발자스러운 의존성.
- 우아한 강등(튜터 없이도 학습 가능)이 설계돼 있어 "차단"이 아니라 "기능 상실"에 그침.
- 그러나 역설: **막혔을 때 물어볼 상대가 가장 필요한 비개발자가 튜터를 못 쓴다.**

### ④ 코드 리터러시

- 노트북 트랙은 `X @ W1 + b1` 같은 코드 읽기를 전제 (계획서에 "대상이 개발자이므로" 명시).
- 비개발자도 셀 실행 + 그래프·출력 읽기는 가능하고 `explain()` 튜터가 보조하지만,
  "두 가지 손맛" 중 노트북 쪽 학습 효과는 반감된다. 비개발자 경로는 사실상 **웹 중심 트랙**.

### ⑤ 자잘하지만 실재하는 것들

- 안내가 전부 Windows 기준(`.venv\Scripts\...`) — Mac 사용자 초반 이탈.
- 노트북 한글 폰트가 `Malgun Gothic` 하드코딩 — **Windows 전용 폰트**라 Mac/Colab 에서는
  개발자여도 그래프 한글이 깨진다 (크로스 플랫폼 이슈).
- GitHub 에서 코드 받기(ZIP 다운로드조차 비개발자에겐 낯섦).

## 2. 완화 방안 (투자 대비 효과 순)

| 우선순위 | 방안 | 효과 / 비고 |
|---------|------|-------------|
| **1** | **웹 앱 정적 배포** (GitHub Pages / Netlify) | Vite 정적 빌드 + localStorage 진도라 서버 불필요 — 거의 공짜. "URL 클릭 → 바로 학습"으로 장벽 ①이 통째로 사라짐 |
| **2** | **노트북 Colab 경로** ("Open in Colab" 배지) | 설치 제로, 브라우저 실행. 손볼 것: `tutor.py`/`tutorContext.json` 상대경로 의존, Malgun Gothic → 나눔폰트 설치 셀 또는 폰트 폴백 |
| **3** | **읽기 전용 노트북** (실행 결과 포함 HTML/nbviewer 게시) | 실행조차 부담인 사람용 최후 폴백 — "읽기만 해도 완결" |
| **4** | **튜터는 개발자 전용 기능으로 인정** | 배포판에는 "로컬 Ollama 있으면 켜짐" 안내만. 클라우드 API 폴백은 키·비용 문제로 현재 철학(무료·로컬)과 충돌 |
| **5** | **비개발자용 시작 가이드 1장** (스크린샷 기반, Mac 병기) | 로컬 실행을 고집하는 사람용. ExecutionPolicy·PATH·커널 선택을 그림으로 |

### 착수 시 작업 메모

- **웹 배포**: 저장소별 GitHub Pages(Actions 빌드) 또는 Netlify. Vue Router 는 history 모드면 404 폴백 설정 필요. 4개(+5부) 저장소에 동일 패턴 반복.
- **Colab 호환 점검 체크리스트**: ① 폰트 셀(나눔고딕 설치 후 rcParams, Windows 에서는 Malgun 유지하는 분기) ② `tutor.py` import 실패 시 안내만 출력하고 계속 진행(현재도 graceful 하지만 파일 자체가 없는 경우 대비) ③ 저장소 파일 의존(tutorContext.json) 없이도 노트북 단독 실행 가능하게.
- 이 문서의 조치가 실행되면 각 부 README 에 "비개발자는 여기서 시작" 섹션 추가.
