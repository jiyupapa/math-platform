## 2. 핵심 설계 철학 (수포자 맞춤)

1. **직관 먼저, 공식 나중** — 3Blue1Brown 스타일. "왜 이게 필요한가"를 그림으로 먼저 보여주고 수식은 마지막에.
2. **글자보다 움직임** — 벡터·변환을 직접 드래그해서 결과가 실시간으로 바뀌는 걸 본다.
3. **작은 성공의 반복** — 짧은 개념 → 바로 자동채점 문제 → 즉시 해설. 막히면 힌트 단계 제공.
4. **두 가지 손맛** — 웹에서 "감"을 잡고, Python 노트북에서 "진짜 계산"을 해본다.
5. **🔑 모든 새 용어·기호·수식은 반드시 설명** — 처음 등장하는 용어/기호/수식은 예외 없이 곧바로 풀어 설명한다.
   수포자는 설명 없는 기호 하나에서 막힌다. 기호는 "이름 + 읽는 법 + 뜻"을 같이 준다.
   예: <code>‖a‖</code> → "이중 막대 기호, '노름(norm)'이라 읽고 벡터의 길이를 뜻함".
6. **🤖 AI 연결 필수** — 각 챕터마다 그 개념이 AI에서 어떻게 쓰이는지 보여준다(프로젝트 최종 목표).
   예: 내적→코사인 유사도/추천/어텐션, 행렬→데이터·가중치, 행렬곱→신경망 층, 고유값/PCA→차원축소·임베딩.

### Phase 1 — 좌표와 벡터란 무엇인가
- 개념: 수직선 → 좌표평면 → 벡터(크기+방향) 직관
- 시각화: 좌표평면 위 점/화살표 드래그, 좌표값 실시간 표시
- 문제: 좌표 읽기, 벡터 성분 찾기 (자동채점)
- 노트북: NumPy 배열로 벡터 만들기, Matplotlib로 화살표 그리기

### Phase 2 — 벡터 연산 (덧셈·스칼라배·내적)
- 개념: 덧셈(평행사변형법), 스칼라배(늘이기/줄이기), 내적과 각도
- 시각화: 두 벡터 드래그 → 합·차 실시간, 내적값과 사잇각 동시 표시
- 문제: 합/차 계산, 내적으로 수직 판별 (자동채점)
- 노트북: `np.dot`, 크기/정규화, 각도 계산

### Phase 3 — 행렬과 행렬 연산
- 개념: 행렬 = 숫자 표, 덧셈/스칼라배, 행렬 곱(행×열)
- 시각화: 행렬 곱셈 셀 단위 애니메이션
- 문제: 곱셈 결과 채우기, 차원 맞추기 (자동채점)
- 노트북: `np.array`, `@` 연산, 차원(shape) 다루기

### Phase 4 — 연립방정식과 가우스 소거법
- 개념: 연립방정식 ↔ 직선의 교점, 행 연산으로 풀기
- 시각화: 두 직선 교점, 소거 과정 단계별 하이라이트
- 문제: 다음 소거 단계 고르기, 해 구하기 (자동채점)
- 노트북: `np.linalg.solve`, 단계별 행 연산 구현

### Phase 5 — 🌟 선형변환 (핵심)
- 개념: 행렬 = 공간을 변형하는 함수, 기저 벡터의 이동
- 시각화: 격자 전체 실시간 변형(회전·확대·전단), 슬라이더로 행렬값 조절
- 문제: 변환 후 좌표 맞히기, 행렬 ↔ 변형 짝짓기 (자동채점)
- 노트북: 변환 행렬 적용, before/after 격자 그리기

### Phase 6 — 행렬식과 역행렬
- 개념: 행렬식 = 넓이/부피 배율, 0이면 역행렬 없음(가역성)
- 시각화: 단위 정사각형 → 변환 후 넓이 변화 애니메이션
- 문제: 행렬식 계산, 가역 여부 판별 (자동채점)
- 노트북: `np.linalg.det`, `np.linalg.inv`

### Phase 7 — 고유값과 고유벡터
- 개념: 변환해도 방향이 안 바뀌는 특별한 축(고유벡터)과 그 배율(고유값)
- 시각화: 변환 중 방향 유지되는 벡터 강조 표시
- 문제: 고유값 계산, 고유벡터 찾기 (자동채점)
- 노트북: `np.linalg.eig`, 고유벡터 시각화

### Phase 8 — 응용 (PCA 등) + 마무리
- 개념: 고유값/벡터의 실제 쓰임 — 데이터 차원 축소(PCA) 직관
- 시각화: 2D 데이터 구름 → 주성분 축 표시
- 문제: 종합 복습 퀴즈
- 노트북: 간단한 PCA 직접 구현, 전체 개념 정리
- 마무리: 학습 요약, 다음 학습 가이드

## 6-B. AI 심화 확장 Phase (9~12) 상세

> 1~8로 "AI 기반 지식의 토대"는 달성. 9~12는 AI 실전에서 자주 쓰는데 1~8에 빠져 있던 핵심을 채운다.

### Phase 9 — 기저·차원·계수(rank)
- 개념: 선형독립/종속, 생성(span), 기저(basis), 차원, 계수(rank) — "벡터들이 진짜 몇 차원어치 정보인가"
- AI 연결: 차원축소·임베딩·특징의 중복성 이해의 바탕. 데이터 행렬의 rank = 실질 정보량
- 시각화: 두 벡터가 평면을 채우는지/한 직선에 갇히는지(종속) 실시간
- 노트북: `np.linalg.matrix_rank`, 선형독립 판별

### Phase 10 — 직교성과 투영
- 개념: 직교(수직), 정규직교기저, 투영(projection), (그람-슈미트). 최소제곱 = 투영으로 "가장 가까운 답" 찾기
- AI 연결: 선형회귀/최소제곱의 진짜 원리, PCA의 직교 축
- 시각화: 한 벡터를 다른 벡터/평면에 투영하는 그림자, 잔차가 수직임을 확인
- 노트북: 투영 공식 구현, 최소제곱(`np.linalg.lstsq`)

### Phase 11 — 🌟 특이값분해(SVD)
- 개념: 임의의 행렬을 회전·확대·회전으로 분해, 특이값, 저랭크 근사
- AI 연결: **ML에서 가장 중요한 분해** — 추천시스템, 차원축소(PCA와 연결), 임베딩, 노이즈 제거, 이미지 압축
- 시각화: 행렬이 단위원을 타원으로 보내는 모습, 특이값=타원 반지름
- 노트북: `np.linalg.svd`, 이미지 저랭크 복원 데모

### Phase 12 — 그래디언트와 행렬미분
- 개념: 기울기→그래디언트(벡터), 경사하강법, 연쇄법칙→역전파 기초 (행렬 형태)
- AI 연결: **AI '학습'의 심장** — 손실을 줄이는 방향으로 가중치 갱신이 전부 이것
- 시각화: 손실 곡면 위 공이 굴러 내려가는(경사하강) 애니메이션
- 노트북: 간단한 경사하강 직접 구현, 수치미분 vs 해석미분
- 비고: 미적분 요소 포함 — 행렬 형태라 'AI 선형대수' 파트로 다룸
