## 슬라이드에 들어갈 텍스트

**제목**
> 단순 강의가 아닙니다 — 수포자가 '끝까지' 가도록 설계

**차별점 (5개)**

| 차별점 | 무엇 |
|---|---|
| ✅ 모든 기호 즉시 설명 | 새 용어·기호·수식은 예외 없이 "이름 + 읽는 법 + 뜻"으로 |
| ✅ 난이도별 문제 + 단계별 채점 | 챕터마다 난이도별 문제, 계산은 **중간 과정까지** 채점(StepQuiz)·즉시 해설 |
| ✅ 복습 북마크 + 진도 저장 | 어려운 섹션 표시 후 모아보기, 진도는 자동 저장 |
| ✅ 웹 + 노트북 병행 | 직관(웹)과 진짜 계산(노트북)을 1:1로 |
| ✅ 매 챕터 AI 연결 | 배운 수학이 AI의 어디에 쓰이는지 항상 연결 |

**하단 핵심 메시지 (한 줄)**
> 수포자가 "설명 없는 기호 하나에서 멈추던" 그 지점을 정조준해 설계했습니다.

## 스피커 노트 (말할 멘트, 약 30초)

> "그런데 이건 단순한 강의 영상이 아닙니다. 수포자가 **끝까지 가도록** 설계했습니다.
> 새로 나오는 기호는 예외 없이 이름·읽는 법·뜻을 즉시 설명하고,
> 문제는 난이도별로, 계산은 답만이 아니라 **중간 과정까지 채점**해 어디서 틀렸는지 바로 알려줍니다.
> 어려운 곳은 북마크해 모아 보고, 진도는 자동 저장됩니다.
> 아까 말한 '설명 없는 기호 하나에서 멈추던' 문제 — 그 지점을 정조준했습니다."

## 제작 메모
- ②문제 제기에서 던진 "설명 없는 기호 하나에서 이탈"을 **하단 한 줄로 회수**(수미상관) → 발표 응집력 ↑.
- 항목 5개는 많아 보이면 **3개로 압축 가능**(기호 즉시 설명 / 단계별 채점 / 복습·진도). 30초 안에 다 못 읽음 — 핵심만 말하고 나머지는 화면으로.
- 체크 아이콘 + 짧은 라벨 위주. 설명 문장은 작게(구두로 보완).
- 이 슬라이드는 "기능 자랑"이 아니라 "②의 문제를 어떻게 풀었나"의 증거로 프레이밍.
