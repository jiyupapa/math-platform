## 프로젝트 정체성

"수포자를 위한 AI 수학 시리즈"의 **9부 — 수치 계산 (내 PC에서 도는 AI의 수학)**. 7부에 이은
**실용 확장 트랙 2탄** — "AI를 이해했다"(1~6부)에서 "AI를 내 PC에서 돌린다"(로컬 Ollama)로
건너가는 마지막 수학. 컴퓨터가 실수(實數)를 담고 계산하는 법 — 비트·부동소수점·반올림 오차·
오버플로·log-sum-exp·fp16/bf16·양자화·GGUF — 를 직접 조작하며 이해하게 한다.
도달점은 **11장(캡스톤 — 7B는 왜 4GB인가)**: 모델 카드의 fp16, Ollama 태그의 `q4_K_M`,
파일 크기가 전부 계산으로 읽히고, 내 PC 메모리에 맞는 모델을 스스로 고르는 상태.
**시리즈의 로컬 Ollama 튜터가 바로 이 수학 위에서 돌고 있다** — 사내 도입(로컬·비용 0) 서사 직결.
핵심 한 줄: **"숫자를 담는 자에는 눈금이 있다 — 눈금의 촘촘함이 품질과 몸무게를 정한다."**

> **상태: ✅ 완결 (2026-07-12) — 전 12챕터(워밍업 + 1~11장) 공개. 스캐폴드부터 완결까지 하루.**
> 챕터 구성·다시 쓰는 수학 매핑은 루트 `README.md` "9부 챕터 구성" 표가 정본.

## 콘텐츠 작성 규칙 (필수 — 대상이 수포자임)

1. 직관 먼저, 공식 나중 — 그림/비유 → 인터랙티브 조작 → 수식.
2. 새 용어·기호·수식은 예외 없이 즉시 설명("이름 + 읽는 법 + 뜻").
   **비유어를 만들면 같은 자리에서 실무 용어와 짝지을 것** — 이 부의 비유 체계(자/눈금):
   고무줄 자=부동소수점(floating point)·눈금 촘촘함=정밀도(precision, 가수 비트)·자의 길이=표현
   범위(dynamic range, 지수 비트)·가장 가까운 눈금으로=반올림 오차(rounding error)·자의 끝=
   오버플로(overflow)·반쪽 자=반정밀도(half precision, fp16·bf16)·눈금 갈아타기·축척 스티커=
   양자화(quantization)·스케일 팩터(scale factor)·숫자의 몸무게=메모리 풋프린트(memory footprint).
3. **"다시 쓰는 수학" 연결 필수** — 각 장이 어느 부의 어느 개념을 다시 쓰는지(루트 README 표)
   `ConceptCard` 로 명시: 2장=5부 1~2장(비트·압축), 3장=2부 7장(지수·로그), 4장=3부 5·7장(오차
   누적·√n), 5장=2부 7장·8부 9장(exp 폭발·스파이크), 6장=4부 9장(softmax)·5부 4장(−log),
   8~9장=3부 5장(분포·아웃라이어), 10장=5부 7장(퍼플렉시티)·6부 9장(평가), 11장=전 시리즈.
   ⚠️ 부 간 링크 전 **해당 부 `chapters.ts` 실물로 장 번호를 재확인**할 것 — 문서 구표기와
   실제 목차가 어긋난 사례 있음(예: 5부 KL 발산은 README 곳곳에 "6장"이지만 실물은 ch5).
4. 문제 표준: 본문 미니체크 2~3개 + 챕터 끝 10문제 `QuizSet`(완료 시 진도 처리). 계산형은 `StepQuiz`.
5. 웹 챕터 ↔ 노트북 1:1, 같은 예제.
6. **실습은 전부 오프라인·결정적** — 미니 비트 시뮬레이터·toy 텐서 양자화를 브라우저/노트북에서
   즉시 돌린다(난수는 시드 고정). 실제 대형 모델 다운로드·GPU 를 요구하지 말 것.
7. 부 간 참조 링크는 "지정석"(AI 연결 카드·완주 박스)에만 `PartLink` 사용, 본문 인라인은 텍스트.
8. **7·8부와의 구도 유지** — 6부 "무엇을 배우게 할까"(데이터·손실) · 8부 "어떻게 잘 배우게
   할까"(다이얼) · 9부 "**무엇으로 담고 계산하나**"(그릇) — 시리즈가 다뤄온 모든 수(임베딩·
   가중치·확률)의 물리적 실체를 다루는 부임을 명시.
9. **분량 방침: 줄이지 않는다** — 장 병합·주제 삭제 금지, 자세한 설명을 위한 확장은 환영
   (2026-07-11 사용자 지침 — 메모리 `content-depth-over-brevity`).

## 자주 막히는 함정

- Ollama 없는 환경에서도 학습이 막히면 안 된다 — 튜터·데모는 항상 폴백을 갖출 것.
- 챕터 라우트를 `router/index.ts` 에 등록하지 않으면 catch-all 이 ComingSoonView 로 보낸다.
- Tailwind `@source`(style.css)가 빠지면 공용 컴포넌트 스타일이 조용히 사라진다 — 빌드는 통과하므로 눈으로 확인.
- **JS `number` 는 fp64 다** — fp32/fp16 을 말로만 설명하지 말고 실제로 재현할 것: fp32 반올림은
  `Math.fround`, fp16/bf16 은 비트 연산으로 직접 구현(노트북은 `np.float16`/`np.float32`).
  웹 시뮬과 노트북 결과가 일치해야 한다(assert).
- 용량 계산은 이진(GiB, 1024³)·십진(GB, 1000³) 구분을 본문에서 즉시 설명 — "7B×4bit≈3.5GB 인데
  왜 파일은 4.1GB?"(블록 스케일·메타데이터 오버헤드)까지 다뤄야 수포자가 안 막힌다.
- 0.1+0.2 같은 예제는 표시 자릿수에 따라 0.3 으로 '보일' 수 있다 — toFixed(20)/전체 자릿수로
  실제 저장값을 보여줄 것.
