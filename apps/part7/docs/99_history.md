### 🌙 다크 모드 — `dark:` 클래스 0개로 전 12앱 전환
앞선 색 토큰화가 깔아 둔 길 위에서 마무리. **마크업을 하나도 안 고쳤다.**

- **방식** — Tailwind v4 는 유틸리티를 `.bg-white{background-color:var(--color-white)}` 처럼
  변수 참조로 내보낸다. 그래서 `packages/ui/src/dark.css` 에서 팔레트 변수(`--color-*`)와
  데모 토큰(`--c-*`) 값만 다시 정의해 전 앱을 한 번에 뒤집었다(레이어 밖이라 @layer theme 를 이긴다).
  값은 손으로 적지 않고 `node_modules/tailwindcss/theme.css`(정본)에서 읽어 생성했다.
- **반전 규칙** — 강조색은 50↔950 · 100↔900 · 600↔400 · 700↔300(500 은 고정).
  중립(slate)은 공식이 아니라 **역할**로 짰다. 라이트의 밝기 사다리와 대비를 맞추는 게 목적이라
  400 은 500 으로만 내린다(양쪽 다 '장식용'): 라이트 slate-400/white ≈ 3.0:1 ↔ 다크 slate-500/slate-900 ≈ 3.4:1.
  표면은 페이지 slate-950 / 카드 slate-900 으로 벌려 카드가 사라지지 않게 했다.
  `--color-black` 은 안 뒤집는다 — 모바일 사이드바 오버레이 `bg-black/30` 은 다크에서도 어두워야 한다.
- **Chart.js** — canvas 는 CSS 변수를 못 읽는다. 자체 기본색(눈금·범례 `#666`)이 다크 카드 위에서
  **2.6:1** 이었다. `ChartView` 가 토큰에서 기본값을 만들어 깔고(사용자 옵션 우선), `themeVersion` 을
  구독해 테마가 바뀌면 다시 그린다 → 축 글자 **5.7:1**.
- **패키지의 plain CSS 3개도 토큰화** — `AuthPanel`·`NoteMarker`·`NotePanel` 에 hex 가 박혀 있어
  다크에서 흰 박스로 남았다. 20건 치환.
- **전환 UI** — `ThemeToggle`(시스템 → 라이트 → 다크 순환), 선택은 localStorage.
  첫 페인트 깜빡임은 각 `index.html` 인라인 스크립트가 막는다(번들보다 먼저 `data-theme` 적용).

**검증 — 라이트/다크 대비를 같은 페이지에서 자동 대조**했다(Tailwind 가 `oklch()` 로 내보내
