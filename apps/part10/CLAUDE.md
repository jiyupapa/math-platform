## 프로젝트 정체성

"수포자를 위한 AI 수학 시리즈"의 **10부 — 스케일링 법칙과 평가의 통계**. **평가·전략 트랙** —
"모델을 키우면 왜/얼마나 좋아지나"(멱법칙·로그-로그·Chinchilla)와 "그 점수 차이가 진짜인가"
(벤치마크 신뢰구간·가설검정·오염·LLM 심판)를 한 서사로 묶어, AI 뉴스·리더보드·모델 카드를
**숫자로 판별하는 눈**을 기른다.
도달점은 **10장(캡스톤 — AI 뉴스 팩트체크)**: 가상의 신모델 발표(기사+모델 카드+리더보드)를 읽고
① 스케일링 주장을 C≈6ND 로 검산하고 ② 점수 차이의 유의성을 오차범위로 판정해 도입 결론을 내는 상태.
**시리즈에서 유일하게 회수되지 않던 3부 8~10장(추정·검정·상관) 심화 트랙의 회수처**이자
6부 9장(조련 성적표)의 정식 심화판. 사내 도입 서사 직결 — "새 모델이 2점 높대요, 바꿔야 하나요?"에
계산으로 답하는 평가 리터러시.
핵심 한 줄: **"성장은 로그-로그 위의 직선이고, 점수 차이는 오차범위 안에선 소음이다."**

> **상태: ✅ 완결 (2026-07-13) — 전 11챕터(워밍업 + 1~10장) 공개. 착수(07-12)부터 이틀.**
> 챕터 구성·회수하는 수학 매핑은 루트 `README.md` "10부 챕터 구성" 표가 정본.
> 진행 상태 추적은 `docs/00_plan.md`.

## 콘텐츠 작성 규칙 (필수 — 대상이 수포자임)

1. 직관 먼저, 공식 나중 — 그림/비유 → 인터랙티브 조작 → 수식.
2. 새 용어·기호·수식은 예외 없이 즉시 설명("이름 + 읽는 법 + 뜻").
   **비유어를 만들면 같은 자리에서 실무 용어와 짝지을 것** — 이 부의 비유 체계(모의고사/황금비):
   곱의 세계의 직선=멱법칙(power law)·몸집과 밥의 황금비=컴퓨트 최적(Chinchilla optimal)·
   훈련 예산=컴퓨트(C≈6ND)·모의고사=벤치마크(benchmark)·오차범위=신뢰구간(confidence interval,
   여론조사 ±3.1%p)·기출 유출=오염(contamination)·AI 채점관=LLM 심판(LLM-as-judge)·
   착시 계단=창발(emergent abilities) 논쟁.
3. **"회수하는 수학" 연결 필수** — 각 장이 어느 부의 어느 개념을 회수하는지(루트 README 표)
   `ConceptCard` 로 명시: 2장=2부 7장(지수·로그)·5부 1장(log₂), 3장=5부 4·7장(손실·PPL)·4부 11장(학습),
   4장=9부 1장(파라미터 수 공식), 5장=5부 7장(지표), **6장=3부 8장(신뢰구간)**, **7장=3부 9장(가설검정·p값)**,
   8장=6부 3장(데이터)·6부 9장, **9장=3부 10장(상관)**·6부 9장, 10장=전 시리즈.
   ⚠️ 부 간 링크 전 **해당 부 `chapters.ts` 실물로 장 번호를 재확인**할 것 — 문서 구표기와
   실제 목차가 어긋난 사례 있음.
4. 문제 표준: 본문 미니체크 2~3개 + 챕터 끝 10문제 `QuizSet`(완료 시 진도 처리). 계산형은 `StepQuiz`.
5. 웹 챕터 ↔ 노트북 1:1, 같은 예제.
6. **실습은 전부 오프라인·결정적** — 시드 고정 이항 시뮬(오차범위), 미니 bigram LM 연작(9부 10장의
   toy LM 재활용 — 데이터량을 늘리며 손실 멱법칙 실측), 예산 배분 곡선, 편향 주입 심판 시뮬.
   실제 대형 모델·외부 API·리더보드 크롤링을 요구하지 말 것.
7. 부 간 참조 링크는 "지정석"(AI 연결 카드·완주 박스)에만 `PartLink` 사용, 본문 인라인은 텍스트.
8. **시리즈 질문 사슬 완성 구도 유지** — 6부 "무엇을 배우게 할까" · 8부 "어떻게 잘" · 9부 "무엇으로
   담나" · 10부 "**얼마나 키우고, 정말 좋아졌나**" — 훈련 전략(스케일링)과 사후 판정(평가 통계)의 부.
9. **분량 방침: 줄이지 않는다** — 장 병합·주제 삭제 금지, 자세한 설명을 위한 확장은 환영
   (메모리 `content-depth-over-brevity`).

## 자주 막히는 함정

- **통계 심화(3부 8~10장)를 안 본 학습자도 막히면 안 된다** — 신뢰구간·p값·상관은 처음 보는
  학습자를 위한 최소 직관을 자체 포함(6부가 LoRA 에 rank 를 자체 포함했던 방식). 단, 3부에서
  배웠다면 "그때 그 공식"으로 회수를 명시.
- **수치는 전부 사전 검증된 결정적 toy 예제** — 신뢰구간 폭·p값·멱법칙 기울기 등 본문 수치는
  노트북 assert 로 고정하고 웹 시뮬과 일치시킬 것(9부 전례: 서사-수치 불일치를 assert 가 잡음).
- 벤치마크·리더보드는 **가상의 이름**을 쓸 것(실존 모델·기관 비방/오인 방지) — 단 수학은 실제
  관행(±1.96√(p(1-p)/n), paired 비교, 창발 지표 논쟁)과 일치.
- 챕터 라우트를 `router/index.ts` 에 등록하지 않으면 catch-all 이 ComingSoonView 로 보낸다.
- Tailwind `@source`(style.css)가 빠지면 공용 컴포넌트 스타일이 조용히 사라진다 — 빌드는 통과하므로 눈으로 확인.
- 로그-로그 차트는 Chart.js `type: 'logarithmic'` 축 — 눈금 라벨이 10^k 로 나오는지 확인하고,
  0 이 들어가면 축이 깨진다(0 대신 최소값 클램프).
