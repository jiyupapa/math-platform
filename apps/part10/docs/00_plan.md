## 장별 필수 소주제 (빠뜨리면 안 되는 것 — 완료 시 [x])

- [x] **① 로그-로그 직선 읽기(2장)** — y = a·xᵇ 가 왜 로그-로그에서 직선이 되나(log y = log a + b·log x),
  기울기 b = "10배 키우면 10ᵇ배" 감각. 어떤 곡선이 어느 종이(선형/반로그/로그-로그)에서 직선이 되는지 대조.
- [x] **② Chinchilla 검산(4장)** — C ≈ 6ND 어림의 유도 감각(순전파+역전파 ≈ 파라미터당·토큰당 6 FLOPs,
  1장에서 선행), 같은 예산에서 N↔D 트레이드오프 곡선의 최저점, "파라미터당 ~20토큰" 어림과 과체격(덜 먹인)
  모델 사례(겅호 280B vs 친칠라 70B 같은 예산 재현 + StepQuiz 검산 C=6×10²²→22B).
- [x] **③ 정확도 신뢰구간(6장)** — ±1.96·√(p(1−p)/n) 공식과 여론조사 ±3.1%p(n=1,000) 짝짓기,
  문항 수 n 별 ±폭 표(100→±9.8%p, 1,000→±3.1, 10,000→±1.0), "벤치마크 문항 수를 확인하는 습관"
  (+냅킨 공식 98/√n StepQuiz, 참값 담기 100회 시뮬로 "95%=절차의 명중률"까지).
- [x] **④ 쌍대 비교의 위력(7장)** — 같은 문항에 두 모델을 붙이는 paired 비교가 독립 표본보다 필요
  표본을 크게 줄이는 이유(공통 난이도 분산 소거 — 필요 표본 3,953 vs 957, 4.1배), 불일치 문항만 세는
  감각(맥니마 z=(x−y)/√(x+y) — n=1,000에서 따로 p=0.324 vs 쌍대 p=0.039 갈림 실측), p값의 실전 복귀.
- [x] **⑤ LLM 심판 편향 3종(9장)** — 위치(+12.5%p 부풀림)·길이(집계 무변·판정 10판 조용한 오심)·
  자기 선호(우위→열세 둔갑)를 시드 고정 시뮬로 주입·측정, 완화책(교차 채점=위치 소거·판정 불가율
  30%가 편향 측정기, 자기선호는 심판 분리)과 심판 간 일치도(77% — 사람 대비 93%보다 낮음, 일치≠정답).

## 설계 메모

- **트랙 성격**: 평가·전략 — 실용(리더보드 리터러시)과 이론 심화(3부 후반 회수)의 결합.
  전반 1~5장 = 성장의 법칙(스케일링), 후반 6~9장 = 시험의 통계(평가), 10장 = 종합 팩트체크.
- **선수 지식**: 3부 전반(확률 기초) 필수, 2부 7장(로그) 권장. 3부 8~10장은 자체 회수(안 봤어도 진행 가능).
- **실습 재료**: 시드 고정 이항 시뮬, 9부 10장의 미니 bigram LM 재활용(데이터량 스윕 → 손실 멱법칙),
  예산 배분 곡선, 가상 리더보드/보도자료(실존 모델명 금지).
