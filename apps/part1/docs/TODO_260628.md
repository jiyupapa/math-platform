## 2. 추가 후보 2차 (⑥~⑭) — 2026-06-28 확장

### AI 테마 심화 — 트렌디한 각도

#### ⑥ 🔥 어텐션/트랜스포머 미니 데모
- ch2에서 "내적 = 어텐션"이라 예고만 한 것을 실제로 구현: **단어 몇 개의 어텐션 행렬을 내적으로 실시간 계산·시각화**.
- "ChatGPT가 문장을 이해하는 게 결국 내적"을 눈으로. 트렌디하고 심사 임팩트 큼.

#### ⑦ 임베딩 평면 데모
- 단어/영화/상품 임베딩을 2D 평면에 띄우고, 드래그·검색하면 **가까운 것=유사한 것** 체험.
- PCA·코사인 유사도·차원축소가 한 화면에서 만남. 캡스톤(②)과 연결 가능.

#### ⑧ "한 문장이 거치는 선형대수" 인포그래픽
- 입력 문장 → 임베딩(벡터) → 어텐션(내적) → 층(행렬곱) → 출력. 배운 챕터가 LLM 파이프라인 어디에 박히는지 **한 장으로**.
- 발표 슬라이드 첫 장으로도 강력.

### 설치 없이 진짜 계산 — 기술적 한 방

#### ⑨ 🔥 브라우저 내 노트북 실행 (Pyodide/JupyterLite)
- 지금 노트북은 따로 설치·실행해야 함 → **브라우저에서 NumPy 코드를 바로 실행**.
- 심사위원이 설치 없이 "진짜 계산"을 돌려봄. 시연 임팩트 매우 큼.

### 효과를 숫자로 — 비전문가 심사 설득력

#### ⑩ 🔥 학습 전·후 자가진단
- 시작 시 "수학 자신감/실력" 간단 진단 → 학습 후 재측정 → **향상도를 그래프로**.
- 수포자 대상 프로젝트의 효과를 정량화 → 비전문가 심사위원에게 가장 잘 꽂힘.

#### ⑪ 게임화 (배지·스트릭·레벨)
- 완료 배지, 연속 학습 스트릭, 챕터별 레벨. 이탈 잦은 수포자를 붙잡는 장치이자 시연에서 "재미있다"는 인상.

### 교육센터·"AI 강사" 테마 직격

#### ⑫ 강사용 발표 모드
- 시각화를 **풀스크린 프레젠테이션 모드**로(슬라이더만 크게, 설명 숨김). 강사가 수업에서 사용.
- 해커톤의 "AI 강사 추천" 키워드와 정확히 맞물림.

#### ⑬ 한/영 다국어 (후순위)
- 콘텐츠 i18n. 글로벌/외국인 교육생 대상이면 차별화. 공수 큼.

### 완성도·접근성

#### ⑭ 3D 시각화 한 챕터
- 지금 전부 2D → **3D 벡터/변환**을 하나라도 보여주면 "공간" 직관 확장(고유값·SVD와 어울림).
- three.js 필요, 공수 중간.

### 2차 후보 우선순위 메모
- **심사 임팩트 최상위**: ⑥ 어텐션 · ⑨ 브라우저 노트북 · ⑩ 학습 전후 진단
- **테마 적중**: ⑥⑦⑧(LLM) · ⑫(AI 강사)
- **재미/완성도**: ⑪ 게임화 · ⑭ 3D
