# 3분 시연 영상 촬영 대본 — 수포자를 위한 선형대수학

> 목표: 3분 안에 ①인터랙티브 학습 ②자동채점 ③AI 튜터(웹) ④코드 설명(노트북) ⑤완전 오프라인을 모두 보여준다.
> 라이브 데모 시에도 같은 대본을 그대로 사용.

## 촬영 전 체크리스트 (5분)

- [ ] `ollama serve` 실행 + **워밍업 질문 1회** (첫 질문은 모델 로딩으로 수십 초 걸릴 수 있음 — 미리 한 번 물어두면 15분간 메모리 유지)
- [ ] 웹: `npm run dev` → `localhost:5173`, **ch2(벡터 연산)** 탭 열어두기
- [ ] 노트북: `jupyter lab` → `ch02_vector_operations.ipynb` 열고 **위에서부터 코사인 유사도 셀까지 실행**해 두기 (튜터 셀 포함 — 🤖 버튼 떠 있는 상태)
- [ ] 브라우저 배율 125% (녹화 화면에서 글씨 잘 보이게), 알림 끄기
- [ ] 진도 일부 채워진 상태로 (완전 0%보다 "쓰고 있는 프로그램" 인상)
- [ ] Wi-Fi 토글을 빠르게 열 수 있게 준비 (마지막 장면)

## 촬영·편집 팁

- **답변 대기 처리**: 튜터 완답은 5~6초 — 스트리밍이 시작되면 그대로 두고, 편집에서 중간을 1.5~2배속 처리하면 리듬이 삽니다. (첫 토큰은 즉시 나오므로 "멈춘 화면"은 안 생김)
- **질문은 복사–붙여넣기**: 오타 리스크 제거. 위 3개 질문을 메모장에 미리 준비.
- **실패 대비**: 튜터 답변은 생성형이라 매번 조금 다릅니다 — 리허설 1회로 답변 톤을 확인하고, 마음에 안 들면 "지우기" 후 재질문 (맥락이 초기화되어 재현성 높음).
- **자막 강조 포인트**: `내적 = 0 (수직)` / `10/10 차단 · +0초` / `Wi-Fi OFF` / `₩0 · 오프라인` — 화면 하단 자막으로.
- 내레이션 총 분량 약 550자 — 보통 속도로 2분 40초 내외라 여유 20초 (화면 전환·스트리밍 감상용).
