# 효과 측정 지표 (1장 요약) — 수포자를 위한 선형대수학

> **무엇을 자동화했나**: ① 튜터(질문 응대·코드 해설) ② 채점·해설 ③ 콘텐츠 품질 검증.
> 표기 구분 — **[실측]** 실제 측정값(과정은 [`99_history.md`](99_history.md) 기록) · **[설계]** 프로그램 설계값 · **[기준]** 일반적 비교 기준.

## 1. 학습 경험 — 시간 절약

| 지표 | 자동화 전 (독학 수포자) | 자동화 후 (본 프로그램) | 효과 |
|---|---|---|---|
| 막혔을 때 질문 → 답변 대기 | 물어볼 곳 없음, 커뮤니티 질문 시 수 시간~수일 **[기준]** | 로컬 AI 튜터 **첫 토큰 즉시, 완답 5~6초** (94 tok/s) **[실측]** | 대기 시간 사실상 0 → **학습 중단 없음** |
| 문제 채점·해설 확인 | 해답지 대조 (문항당 수 분, 해설 없는 경우 다수) **[기준]** | **자동채점 문항 170여 개** — 즉시 채점 + 단계별 힌트 + 해설 **[설계]** | 채점 대기 **0초**, 오답 시 즉시 교정 |
| 실습 코드 이해 | 코드 한 줄마다 검색 또는 포기 **[기준]** | 📖 **코드 설명** 클릭 1번 — 실행한 셀을 챕터 개념과 연결해 해설 **[실측]** | 검색 왕복 제거 |
| 전 과정 완주 학습량 | 대학 한 학기 강의 약 45시간(3학점×15주) **[기준]**, 독학은 중도 포기가 다수 | **총 8.5시간** (워밍업+12챕터, AI 연결 포함) **[설계]** | 완주 가능한 분량으로 재설계 (약 1/5) |

## 2. AI 튜터 — 오류율·응답 품질 [실측]

| 지표 | 대안 방식 (기각) | 채택 방식 (센티널 가드레일) |
|---|---|---|
| 주제 이탈 차단 정확도 | 분류 호출 게이트: **8/10** (기초 수학 질문 오차단 발생) | **10/10** — 잡담·대행 요청 차단, 인사·기초 수학·학습 고민은 통과 |
| 가드레일 추가 지연 | 질문당 **+4초** (별도 LLM 호출) | **+0초** (스트리밍 첫 부분 보류 감지) |
| 챕터 맥락 정합 | 경량 모델 단독: 함정 질문 오답 | 챕터 맥락 주입 후 **함정 질문 정답** (예: "음수 λ면 왜 고유벡터?") + 목차 안내 **5/5** |

## 3. 비용 절감 [실측]

| 항목 | 클라우드 LLM 튜터 | 본 프로그램 (로컬 Ollama) |
|---|---|---|
| API 비용 | 질문당 과금 (학습자·질문 수에 비례해 증가) | **₩0** — 질문 무제한, 학습자 수 무관 |
| 인터넷·계정 | 필수 (API 키 발급·관리) | **불필요** — 완전 오프라인 동작 (시연 가능) |
| 개인정보 | 학습자 질문이 외부 서버로 전송 | **외부 전송 0건** — 전 과정 로컬 처리 |

## 4. 콘텐츠 품질 — 오류(이탈 위험) 감소 [실측]

| 지표 | 값 |
|---|---|
| 1차 수포자 페르소나 검수 (전 챕터 4트랙) | 이탈 위험·결함 **40여 건 발견 → 전량 수정** |
| 수정 후 재검수 | **이탈위험급 잔존 0건**, 12개 챕터 전원 "수포자 학습 적합" 판정 |
| 2차 재검수 (ch0~12 + 노트북) | 추가 보완 **27건 반영** (용어 무설명·논리 비약·문제 중복 등) |
| 회귀 방지 자동 검증 | 수동 QA → **명령 2개로 자동화**: `vue-tsc` 빌드(타입·템플릿) + 노트북 13개 `nbconvert` 무에러 실행 — 매 변경마다 수행 |

**요약 한 줄**: 사람 튜터 없이도 — 질문 응대(6초·₩0·오프라인), 채점(170문항 즉시), 품질 검증(명령 2개)을 자동화해,
수포자가 **8.5시간에 벡터→역전파를 완주**할 수 있는 학습 경험을 만들었다.
