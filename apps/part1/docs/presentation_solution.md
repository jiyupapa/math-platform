## 슬라이드에 들어갈 텍스트

**제목**
> 수포자를 위한 선형대수 — 직접 만지면서 배우는 AI의 수학

**두 갈래 학습 (나란히)**

| 🖥️ 웹 앱 — 직관·인터랙션 | 🐍 Python 노트북 — 진짜 계산 |
|---|---|
| 벡터·격자를 슬라이더로 움직여 결과가 실시간으로 바뀌는 걸 본다 | 같은 개념을 NumPy로 직접 계산해 손에 익힌다 |
| "감"을 잡는 곳 | "계산"을 해보는 곳 (챕터와 1:1 대응) |

**콘텐츠**
> 8개 챕터: 벡터 → 연산 → 행렬 → 연립방정식 → 선형변환 → 행렬식·역행렬 → 고유값 → PCA

**AI 연결**
> 🧠 모든 개념을 신경망의 '부품'으로 연결 — 배운 수학이 AI 어디에 쓰이는지 매 챕터에서 보여줌

**하단 핵심 원칙 (한 줄)**
> 글자보다 움직임 · 직관 먼저, 공식 나중

> 다른 하나는 **Python 노트북**: 같은 내용을 NumPy로 직접 계산해 손에 익힙니다.
> 그리고 매 챕터마다, 그 수학이 **신경망의 어느 부품인지** 연결해 보여줍니다.
> 핵심 원칙은 하나 — **글자보다 움직임**. 직접 보여드리겠습니다."
