- **형식**: 업무구조도형 스윔레인 — 열 = 학습 국면 8개(진단 → 토대 I → 조립 I → 토대 II →
  조립 II → 본체 → 조련 → 확장·완주), 행 = 트랙 3레인(필수 / 선택·심화 / 선택·실용),
  노드 13개(경로 11단계 + 진단·완주). 실선 = 필수 흐름, 점선 = 선택 분기 진입
  (7부←1단계, 8·9부←4단계 — 루트 README 추천 경로가 정본).
- **파일**: `data/structure.ts`(배치 데이터) + `views/StructureView.vue`(보드 · SVG 연결선 ·
  상세 패널). 라우트 `/map`, 헤더 내비 "학습 구조도" + 홈 지도 옆 "전체 구조도 보기 →".
- **살아 있는 지도**: 노드 상태가 실데이터에서 나온다 — 진도(2층 `readStepProgress`)로
  완료/진행 중(막대), 진단(`recommend` 규칙 엔진)으로 빠른 복습·이미 앎·다음 목적지,
  무진단이면 진단 노드가 "여기서 시작". 스탯 스트립에 개인화 요약("당신의 경로 N챕터·M시간").
- **?node= 딥링크**: 노드 선택 ↔ URL 동기화(공유 가능), 상세 패널(분량·진도·진입 조건·
  "학습하러 가기"). "핵심 흐름 / 전체 구조도" 토글(선택 레인 숨김·연결선 재계산).
- 검증: 포털 빌드(vue-tsc) + 조립본 E2E(신규/개인화/딥링크 3상태 스크린샷, 콘솔 에러 0) +
  전 플랫폼 스모크 **117/117**(구조도 편입 — 종전 116).
- **(사후 수정) 노드 클릭 시 화면이 맨 위로 튀던 문제** — 라우터 전역 `scrollBehavior`(top:0)가
  `?node=` 쿼리 내비게이션에도 적용된 것이 원인. 같은 경로에서 쿼리만 바뀌면 위치를 유지하도록
  수정하고, 선택 시 상세 패널을 `scrollIntoView`로 시야에 끌어옴(보드가 화면을 다 차지하면
  패널이 화면 밖에 열리던 문제). S8 진입 점선 2가닥이 겹쳐 실선처럼 보이던 것도 1가닥으로 정리
  (두 선수 조건은 상세 패널 진입 조건에 명시). E2E 재검증: scrollY 유지 + 패널 뷰포트 내 확인.
