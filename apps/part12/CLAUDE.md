## 프로젝트 정체성

"수포자를 위한 AI 수학 시리즈"의 **12부 — 시스템 다이내믹스**. **전략 트랙** —
"AI에게 일을 맡겨도 되나"(11부)를 넘어 "**들이고 나면 시간이 지나며 무슨 일이 벌어지나**":
쌓이는 것(저량)과 흐르는 것(유량), 돌아오는 고리(강화·균형 루프)와 지연이 시간의 모양
(지수 성장·목표 추구·S자·출렁임)을 만든다는 것을 직접 시뮬레이션하며 익힌다.
시리즈에 없던 **적분·미분방정식·시간에 따른 변화**의 자리이고, 경사하강(오일러법)·EMA(1차 지연)·
시그모이드(로지스틱 성장)가 같은 수학이라는 것을 확인한다.
도달점은 **12장(캡스톤 — 사내 AI 도입, 모형으로 미리 돌려 보기)**: 가상 회사의 AI 도입을
Bass 확산 모형(+ 이탈)으로 돌려 홍보(p)·입소문(q)·이탈 방지(L) 중 무엇이 속도와 최종 수준을
정하는지 판정하고 도입 전략 판정서를 쓰는 상태.
핵심 한 줄: **"쌓인 것은 흐름으로만 바뀌고, 흐름은 쌓인 것을 보고 정해진다."**

## 콘텐츠 작성 규칙 (필수 — 대상이 수포자임)

1. 직관 먼저, 공식 나중 — 그림(인과지도) → 조작(저량-유량도 + 다이얼 시뮬레이션) → 수식(미분방정식).
2. 새 용어·기호·수식은 예외 없이 즉시 설명("이름 + 읽는 법 + 뜻").
   **비유어를 만들면 같은 자리에서 실무 용어와 짝지을 것** — 이 부의 비유 체계:
   욕조의 물 높이=저량(stock)·수도꼭지·배수구=유입·유출(inflow·outflow)=유량(flow)·눈덩이=강화 루프
   (reinforcing loop, R)·온도 조절기=균형 루프(balancing loop, B)·샤워기 온도 맞추기=지연(delay)이 만드는
   과잉 교정(overshoot)·시간을 잘게 썰기=오일러법(Euler's method)과 시간 간격(DT).
3. **용어 표기 고정**(국내 SD 교재·학회 표기 기준, 설계 문서 §5): 저량·유량·유입·유출·순유량, 인과지도(CLD),
   저량-유량도(SFD), 강화 루프·균형 루프(양/음의 피드백은 별칭으로 한 번만), 평형('균형 루프'와 헷갈리지 않게
   '균형점' 대신 평형), 시스템 원형 이름은 영문 병기.
4. **"다시 쓰는 수학" 연결 필수** — 루트 README 12부 표: 워밍업=2부 1장, 1장=11부 1장·2부 9장, 2장=2부 2~3장(거꾸로)·
   8부 4장, 3장=2부 7장·10부 2장, 4장=2부 9장·8부 2장, **5장=8부 2장(학습률 = DT)**·2부 9장·9부 4장,
   **6장=8부 4~5장(EMA = 1차 지연)**, 7장=2부 7장·6부 4장·10부 2장, 8장=8부 10장·8부 4장·1부 7장,
   9장=3부 10장·7부 8장·11부 6장, 10장=11부 6장·10부 8장, 11장=6부 5·6·9장·4부 12장·3부 6장, 12장=전 시리즈.
   ⚠️ 부 간 링크 전 **해당 부 `chapters.ts` 실물로 장 번호를 재확인**할 것.
5. 문제 표준: 본문 미니체크 2~3개 + 챕터 끝 10문제 `QuizSet`(완료 시 진도 처리). 계산형은 `StepQuiz`.
   **QuizSet 제목·문항 문구는 풀이 기록의 키** — 공개 뒤 고치면 `node scripts/quiz-aliases.mjs`(루트 CLAUDE.md).
6. 웹 챕터 ↔ 노트북 1:1, 같은 예제·같은 수치(노트북 assert 로 고정).
7. **실습은 전부 오프라인·결정적** — 난수 없음. 오일러법(대개 DT = 1/16, 캡스톤 1/64). 외부 SD 도구(Vensim·
   Stella·PySD) 설치를 요구하지 말 것(소개만). 노트북은 numpy·matplotlib 만.
8. 부 간 참조 링크는 "지정석"(AI 연결 카드·완주 박스)에만 `PartLink`, 본문 인라인은 텍스트.
9. **시리즈 질문 사슬 유지** — 6부 "무엇을" · 8부 "어떻게" · 9부 "무엇으로" · 10부 "얼마나·정말로" ·
   11부 "이제 일을 맡겨도 되나" · 12부 "**들이고 나면 무슨 일이 벌어지나**".
10. **분량 방침: 줄이지 않는다** — 장 병합·주제 삭제 금지, 자세한 설명을 위한 확장은 환영.

## 자주 막히는 함정

- **고리의 분류를 일관되게** — 같은 비율로 줄어드는 지수 감쇠는 "목표가 0인 균형 루프"(4장),
  줄수록 더 빠른 비율로 줄어드는 것이 악순환(강화 루프). 11장 모델 붕괴(폭 × 0.880)는 앞쪽이다.
- **인과지도 극성은 '원래보다'로 읽는다** — 유량 → 저량의 + 는 "더 쌓인다"이지 "늘어난다"가 아니다(9장, Richardson 1986).
- **장난감 모형임을 밝힌다** — 11장 모델 붕괴(±2σ 절단)·보상 해킹(품질 = e − 0.1e²)은 구조를 보이려는 단순화.
- **반올림 숫자는 실험 화면 표시와 맞출 것** — 본문 숫자는 노트북 출력(round)과 실험 표시(toFixed)를 대조
  (예: 캡스톤 홍보 효과 9.13 − 6.36 = 2.8개월, 플라이휠 8,030명).
- 인과지도 좌표: 루프 기호(R/B)는 루프 안쪽에 두면 이름 자리는 `CldDiagram` 이 고른다. 그래도 빽빽하면 기호 위치를 옮길 것.
- 휴대폰 폭: 좌표 그림은 화면에 맞춰 통째로 줄어든다(가로 440 → 휴대폰 약 0.68배, 글자 8px대). 글자가 중요한 넓은 그림은
  좁은 화면용 좌표를 따로 둔다 — 12장 `AdoptionLab`(화면 폭 480px 이하 → 가로 320)이 본보기.
- Vue 템플릿 속성 안에서 큰따옴표(")를 쓰면 속성이 끊긴다 — 문구 속 인용은 ‘’ 나 「」.
- 챕터 라우트를 `router/index.ts` 에 등록하지 않으면 catch-all 이 ComingSoonView 로 보낸다.
- Tailwind `@source`(style.css)가 빠지면 공용 컴포넌트 스타일이 조용히 사라진다.
- KaTeX 백슬래시: 정적 `expr="..."` 는 1개, JS 바인딩(StepQuiz steps 등)은 2개. 부등호는 `\lt`·`\gt`.
